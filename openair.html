OpenAir

OpenAir is a piece of speculative design exploring the commodidification of air. It provides users with a subscription service for access to purified, clean air in a world that has been overrun by pollution and climate change. Through a wearable filtration device, users can experience what breathing is supposed to feel like; they never have to inhale polluted air again.

The materials created for this design concept include a brochure, an advertisement campaign, and a prototype for a mobile application.

Brochure Prototype Report

Why?

This project was created for the Speculative Design module at the University of York.

Tools

The brochure and advertisement material was created using Adobe Photoshop, while the prototype was built using Figma.

Outcome

This project earned a 1st class grade (72%).
